# Guía de Identificación - Simulador AEAT 2025 (Cataluña)

Para realizar las pruebas del oráculo de Cataluña, se deben seguir estos pasos exactos en la primera página:

## 1. Datos Personales
- **NIF:** `12345678Z`
- **Primer Apellido / Nombre:** `TEST CATALUÑA`
- **Fecha de Nacimiento:** `01/01/1980`
- **Sexo:** Seleccionar `Hombre` o `Mujer` (según caso, por defecto `Hombre` para SAL-CAT).

## 2. Manejo de Desplegables (Crítico)
El simulador usa el framework ZK. No intentes seleccionar con el ratón en la lista flotante, es inestable para el robot. Usa este protocolo:

### Estado Civil
1. Clic en el campo `Estado Civil`.
2. Escribir `Soltero/a`.
3. Pulsar la tecla `ENTER`.

### Comunidad Autónoma
1. Clic en el campo `Comunidad Autónoma / Ciudad con Estatuto de Autonomía`.
2. Escribir el código `09` (correspondiente a Cataluña).
3. Pulsar la tecla `ENTER`.

## 3. Finalización
- Pulsar el botón **Aceptar** en la parte inferior derecha.
- Si aparece un aviso de "Traslado de datos", pulsar **Aceptar** (Nueva Declaración).

---
*Nota: Este protocolo garantiza que el simulador cargue las tablas de retención y escalas autonómicas de la Generalitat de Catalunya correctamente.*
